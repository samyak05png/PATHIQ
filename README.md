# 🧠 PATHIQ

<div align="center">

### Your AI-Powered Path to Smarter Learning 🚀

**PATHIQ** is an AI-powered personalized learning platform designed to help students learn smarter—not harder. It analyzes a learner's goals, available study time, preferred learning style, and progress to create a personalized learning path.

[🌐 Live Demo](https://samyak05png.github.io/PATHIQ/)

</div>

## 🎯 The Problem

Every student learns differently, but traditional learning platforms often provide the same content and sequence to everyone. Students can struggle to decide:

- What should I learn first?
- Which topics should I focus on?
- How much time should I spend studying?
- What should I do when I fall behind?
- Am I actually making progress?

PATHIQ addresses these challenges with an adaptive, personalized learning experience.

## 💡 Our Solution

PATHIQ uses AI-driven personalization to turn a student's goals and learning data into an actionable study journey.

### ✨ Key Features

- 🤖 **AI-Powered Learning Paths** — Generate a structured path based on individual learning needs.
- 🎯 **Goal-Based Learning** — Start with an academic or career goal and work toward it step by step.
- 📊 **Personalized Progress Tracking** — Monitor learning progress and identify areas that need attention.
- 🧩 **Adaptive Learning Experience** — Adjust the learning journey according to student performance and progress.
- ⏱️ **Time-Aware Planning** — Build study plans around the student's available study time.
- 🎮 **Gamified Learning** — Use XP, levels, and progress milestones to make learning more engaging.
- 📚 **Multi-Subject Support** — Designed for learning across different academic subjects.
- 📱 **Responsive UI** — Built to provide a smooth experience across desktop and mobile screens.

## 🏗️ How PATHIQ Works

```text
Student Goal
```

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/samyak05png/PATHIQ.git
```

2. Open the project directory:

```bash
cd PATHIQ
```

3. Install dependencies:

```bash
npm install
```

4. Configure your environment variables as required by the project. For Gemini-powered features, add your API key to `.env.local`:

```env
GEMINI_API_KEY=your_api_key_here
```

5. Start the development server:

```bash
npm run dev
```

6. Open the local URL shown in your terminal.
